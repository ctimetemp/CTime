Notice text

Bumping the notice version replaces the text every agent must show and returns every approved device to the approval queue. Consent is never inherited across a bump -- that is the point of it.

Saving the same version with new wording does not reset consent; change the version string to force everyone to acknowledge again.

Disclosed monitoring. Agents run as a named Task Scheduler job “CTTIme Endpoint Visibility”, write a local log, and can be uninstalled with uninstall.ps1. Clipboard content is never collected: only a character count, a SHA-256 and a kind label. Screenshots are never analysed by OCR or image recognition. Notice version in force: 2026-10-15.1.
