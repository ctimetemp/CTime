How this works

Two programs. The collector is the one serving this page: it keeps the database and shows you what it received. An agent is the small program installed on each computer, which sends that data. Nothing is collected from a computer until three things have happened, in order.

  1. The person is told. On their computer the agent prints a plain-English notice saying what is watched and how often. They read it and type their own name to agree, or type no to refuse. Refusing writes a DECLINED.txt file and that computer never sends anything.
  2. The agreement is recorded. Their name and the exact wording they agreed to are stored, and appear on that device's page. That is a record of consent, not of their activity.
  3. An admin approves. Someone clicks Approve in the approval queue on Overview. Until that click the agent has nowhere to send data, even if the person agreed.

Approving is not permanent: revoking a device puts it back through steps 1 to 3, and editing the notice wording on the Policy page sends every device back to step 1.

What this system cannot do

There is no text here to read. Clipboard content is hashed in the agent's memory, and only that hash, a character count and a coarse label are ever sent. No column in the database could hold the words, no log line writes them, and screenshots are stored as pictures -- never read by optical character recognition or any other image analysis.

It also never hides itself. There is no process or task hiding, no interference with antivirus, and no way to install it on a computer from elsewhere: someone has to run the installer while that person is signed in.

On a computer being monitored

Everything lives in one folder, C:\ProgramData\CTTIme. Inside it ABOUT.txt says in plain words what is installed, the agent itself is readable JavaScript rather than a compiled blob, and agent.log records what it did -- including every time it refused to collect. A device user can read all of it without any permission beyond opening the folder.

To stop and remove it, run uninstall.ps1 in that folder. The scheduled task is named CTTIme Endpoint Visibility and appears in schtasks /query and in Task Scheduler. It runs only while that person is signed in, under their own limited account, and stores no password anywhere.

Network

One port: 8443, encrypted, carrying both this page and the agents' uploads. Agents connect outward and listen on nothing. There is no unencrypted fallback.

Every login to this dashboard is a full administrator. Anyone who can sign in can approve devices and read every screenshot. Make one account per person and do not share it.
