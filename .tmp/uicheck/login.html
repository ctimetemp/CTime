This dashboard is the administrative view of a disclosed monitoring collector. Access is logged. Every approval, revocation, export, policy write and screenshot view is recorded in the audit log with your account name and address.

Disclosed monitoring. Agents run as a named Task Scheduler job “CTTIme Endpoint Visibility”, write a local log, and can be uninstalled with uninstall.ps1. Clipboard content is never collected: only a character count, a SHA-256 and a kind label. Screenshots are never analysed by OCR or image recognition.
